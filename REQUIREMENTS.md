Requirements 

1) The calculator must be able to add 2 numbers eg. 2 + 3 = 5
2) The calculator must be able to subtract 2 numbers eg. 5 - 3 = 2
3) The calculator must be able to multiply 2 numbers eg. 4*2=8
4) The calculator must be able to divide 2 numbers eg. 4/2=2
5) The calculator must display an error message when dividing by 0
