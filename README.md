# Calculator lab project
## How to run it

python 3 is required;
start with ./run.sh;
test 6 * 7 for Result: 42.0;
stop with Ctrl+C

## How to run automated test

python 3 is required;

use source /opt/python-venv/sccm-4910/bin/activate to activate the SCCM4910 virtual environment
start with ./check.sh
Expected test results: 1) 5, 2) 3, 3) 2, 4) 12, 5) 2.5;
echo $? for exit status - 0 means all test passed, 1 means one or more tests failed
